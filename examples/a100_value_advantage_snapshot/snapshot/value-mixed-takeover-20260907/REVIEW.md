# PiperX 混合轨迹 Value：训练与六个 checkpoint 完整诊断

本报告基于 A100 实际生成的 regular/dense metrics 与 held-out advantage 记录。
训练、六个 checkpoint 同条件 advantage 推理、匹配分析和图表均已完成。A100八卡已空闲。
结论：本轮 value 回报预测优先保留1000步候选；没有任何一个checkpoint证明了可靠的接管前动作识别或RL收益。

## 实验范围

- 纯视觉 SigLIP value，429,182,729 参数，无语言/state 输入；不是策略训练。
- Demo558 分为502训练/56留出；完整HIL141分为127训练/14留出。
- 每步 global32，16帧Demo+16帧HIL，各来源内部均匀有放回抽帧，seed1000。
- 1500步，4卡×8，FP32参数/BF16 autocast，warmup200，峰值5e-5，余弦至1e-6。
- 成功终点0，其他帧-1，接管前自主帧额外-150；Z=训练最大累计成本15337，不乘2。
- 最后训练日志：step1500，最近10步平均Loss2.927212，grdn6.896558，lr1e-6。
- 每250步checkpoint均保留；1500已被dense及advantage评估严格重新加载。

| 来源 | 训练 CE | 留出 CE | 训练 MAE | 留出 MAE | 留出 RMSE | 留出 CRPS |
|---|---:|---:|---:|---:|---:|---:|
|Demo|2.14784|2.37392|0.00981|0.01388|0.01999|0.00916|
|完整HIL|3.28998|4.63739|0.02387|0.08932|0.12157|0.06825|

HIL内部也有明显差异：HF来源留出MAE0.05600，4090A来源0.11431。
90%预测区间覆盖率：Demo93.36%，HIL62.72%（HF77.60%，4090A51.56%）。
HIL预测区间明显覆盖不足；不能由训练MAE很低推断其不确定性校准良好。
这些现象不能单独确定原因：来源场景/策略差异、轨迹剩余成本的视觉歧义、标签终点
和成功信息的不确定性都可能参与。4090A75条成功是用户确认，不是原始元数据字段。

本轮Z不同于旧实验，不能直接把旧CE/归一化MAE拿来数值横比。
MAE×15337/30表示含接管惩罚的成本等效秒，不是实际剩余时间误差。

## 接管前 advantage：没有支持可靠识别的强证据

固定14条HIL留出轨迹，71次接管；分类统计仅使用每5帧抽取的自主帧网格。
主窗口50帧（1.67秒），该网格上的接管前正例率4.36%。

| 指标 | 完整advantage | 时间奖励+预测V差 |
|---|---:|---:|
|AUROC|0.65286|0.53166|
|AUROC 95% episode bootstrap|0.62658–0.68537|0.50433–0.56136|
|Average precision|0.06163|0.04362|
|接管前窗口 A<0 比例|76.34%|56.76%|
|非接管窗口 A<0 比例|51.50%|51.50%|

![Advantage分解诊断](figures/advantage_diagnostics.png)

![真实接管事件对齐的均值曲线](figures/pre_takeover_decomposition.png)

完整advantage中的负比例看似较高，但非接管窗口也有约一半为负。
去掉显式扣分后AP几乎等于正例率基线；AUROC虽在主窗口略高于0.5，但效果很弱。
15/30帧窗口的时间+V差AUROC约0.516/0.512，结论类似。

显式惩罚本身由实际接管事件定义，所以其AUC/AP=1是定义造成的，完全不能作为模型能力。
即使时间+V差也使用未来图像；这里只是离线事件相关性诊断，不是在线预警、因果动作质量
或策略成功率验证。非接管也不是“好动作”的真值，以上误报仅相对于该代理标签定义。
完美复现单条轨迹的MC回报会使对应n-step残差恒为0，因此不能假设更低MAE必然带来更好advantage。

## 六个 checkpoint 的同条件 advantage 比较

全部checkpoint都严格加载并在相同57378个窗口上完成推理。以下n=50主窗口，
AUROC来自自然自主帧网格；配对正确率来自独立的时间进度匹配分析。

|Step|完整A AUROC|时间+V差 AUROC|匹配后时间+V差配对正确率（95%CI）|
|---:|---:|---:|---:|
|250|0.6904|0.5376|49.15%（43.10–54.05%）|
|500|0.6540|0.5379|48.73%（42.77–54.58%）|
|750|0.6565|0.5500|47.32%（42.86–51.64%）|
|1000|0.6695|0.5313|49.44%（45.26–52.76%）|
|1250|0.6550|0.5320|50.99%（45.08–56.87%）|
|1500|0.6529|0.5317|51.97%（46.23–58.20%）|

![Checkpoint advantage比较：蓝色完整A，橙色时间+预测V差，灰线随机基线](figures/checkpoint_advantage_comparison.png)

匹配规则在不看预测值的条件下固定：同episode、完整50帧窗口、时间进度距离不超过
episode长度5%、两个窗口不重叠，为每个接管前网格窗口取最近非接管窗口；控制窗口
起点不重复使用，按正例时间顺序匹配。710/710个正例窗口全部匹配，覆盖14条episode；
进度差中位数0.608%。配对正确率定义为接管前A小于控制A的比例，同值算半分。
95%区间使用1000次整episode重采样。它不是视觉/state相似性匹配，邻近窗口仍相关，
不是因果动作质量评估；没有在强制1:1配对样本上计算自然发生率的AP。

1000步匹配后的A<0比例：完整A接管前79.72%、控制60.14%；时间+V差接管前60.56%、
控制60.14%，差值0.42个百分点（95%CI -9.06至7.25）。1500步对应时间+V差差值
1.55个百分点（-6.82至10.00）。所有checkpoint的配对正确率区间都包含50%。

事件层面，以接管前50帧中“至少一帧负A”计算，六个checkpoint的完整A和时间+V差
都覆盖71/71次接管；但这有大量尝试机会，且控制窗口负比例很高，不能宣称100%有效识别。
1000步有88.73%的事件在此前窗口多数帧完整A为负，时间+V差仅61.97%；1500分别为
84.51%和56.34%。阈值始终A<0，未为提高负比例调阈值或惩罚。

## 选型与边界

- 若要继续做value回报预测实验：保留本轮1000步checkpoint作为主候选，1500作为端点对照。
- 不因250完整A AUROC最高就选250：显式事件罚分直接参与了评分，而其回报MAE明显较差。
- 不把1000的候选结论解释为总训练步数1000最优：学习率仍来自原1500步余弦周期。
- 当前单seed和14条HIL留出轨迹，不足以证明小幅checkpoint差异具有统计显著性；留出集已参与选型。
- 没有证据支持“更低value MAE必然产生更好advantage”，也没有跑策略训练/真机成功率验证。
- 不新增训练、不改C150/Z15337、不恢复旧队列；数据、全部checkpoint和日志保留。

原始完整指标（含各来源train/heldout CE、MAE、RMSE、CRPS、区间覆盖率，及每个checkpoint的
配对和事件统计）在 `results/checkpoint_comparison.json`；可复现分析为 `compare_checkpoints.py`。
