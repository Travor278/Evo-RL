# Value 五结构实验：停止后的最终汇总

## 结论先行

- **从已经保存的模型中，优先挑一个用于标量 value 预测：旧完整版 checkpoint-003000.pt。** 它在相同留出 episode/帧上比纯视觉1500的 MAE 更低；继续到4750/6000没有可信的实质收益。它的概率分布过度自信，不能把输出区间当可靠置信区间。
- **若确定一个已验证、可从头运行且较省时的固定步数配方：纯视觉 vision_only，固定1500步，取最终checkpoint。** 它是四组已完成同日程实验中 MAE/RMSE/CRPS 的数值最优，且没有 Gemma/任务/state 分支。与 task_only 的差距不显著，不称为唯一赢家。
- 这两条回答不同问题：前者选已有checkpoint，后者选固定训练预算。没有证据说“纯视觉1500在所有指标上超过旧完整版3000”，也没有证据说“从头固定3000日程等于旧模型的第3000步”。

## 实验已经停止

2026-09-06 按用户要求停止调度和正在运行的完整输入组；8GPU进程全部退出，显存/利用率均为0。15分钟 value 监控已删除。所有已有模型、数据、日志、缓存保留。
新 fixed1500 对照：4/5完成；full最后记录step460（batch loss2.944211、grdn7.678089、lr4.53209e-5），最后完整checkpoint/评估是250。**第5组固定1500没完成；固定2500/3000完全未运行。** 不会继续补跑。

## 1. 五种结构分别是什么

| 结构 | 实际输入 | 哪些encoder更新 |
|---|---|---|
| full | 3相机＋任务文字＋逐帧state token | 视觉、Gemma都更新 |
| vision_only | 仅3相机；没有语言、没有state，也没有替代state MLP | 视觉更新；Gemma删除 |
| frozen_language | 3相机＋任务＋state | 视觉更新，Gemma冻结且eval |
| frozen_both | 3相机＋任务＋state | 视觉、Gemma都冻结且eval；投影/价值头更新 |
| task_only | 3相机＋任务文字，没有state | 视觉、Gemma都更新 |

纯视觉的融合维度为512，其余1024；所以纯视觉不是只去掉语言文字的单因素消融。full与task_only的同日程最终对照未完成，不能由此精确归因state的作用。

## 4. 不同步数如何选

### 新固定1500日程：各保存点的留出 Loss / MAE

所有条目都来自同一条1500日程中的checkpoint，不是从头固定500/750/1000/1250的独立训练。

| 结构 | 250 | 500 | 750 | 1000 | 1250 | 1500 |
|---|---:|---:|---:|---:|---:|---:|
| 完整版：图像＋任务＋state | 3.305 / 0.05559 | 未完成 | 未完成 | 未完成 | 未完成 | 未完成 |
| 纯视觉：无语言、无state | 2.938 / 0.03776 | 2.747 / 0.02399 | 2.555 / 0.01683 | 2.487 / 0.01427 | 2.487 / 0.01373 | 2.481 / 0.01343 |
| 冻结语言：视觉可训练 | 3.297 / 0.05135 | 2.730 / 0.01939 | 2.557 / 0.01630 | 2.501 / 0.01462 | 2.495 / 0.01462 | 2.473 / 0.01412 |
| 冻结视觉和语言 | 3.729 / 0.05837 | 3.420 / 0.04818 | 3.227 / 0.04005 | 3.131 / 0.03705 | 3.072 / 0.03368 | 3.062 / 0.03329 |
| 图像＋任务：无state | 3.100 / 0.03881 | 2.785 / 0.02127 | 2.530 / 0.01625 | 2.488 / 0.01437 | 2.522 / 0.01432 | 2.508 / 0.01382 |

固定1500配方推荐取最终1500：四个完成组的常规MAE/RMSE/CRPS最低点都在1500；纯视觉的CE最低点也在1500。task_only的CE最低点在1000，但到1500 MAE/RMSE/CRPS进一步改善，因此若用于标量value，不单凭CE最小值改选1000。冻结双encoder虽最低点在1500，绝对质量仍不推荐。
纯视觉从1000→1500：留出MAE0.014267→0.013428；1250→1500只改善约0.000305，约0.15秒。它已进入边际收益较小区间，但不能由此断言更长日程一定无收益。**2500、3000固定短日程没有结果，不作虚构比较。**

旧完整版推荐3000，而不是把4750的瞬时最低MAE当唯一答案。3000相对1500的MAE改善0.001179（约0.58秒），旧配对CI不含0；4750相对3000只改善0.000081（约0.04秒），CI[-0.000819,0.000662]含0，而CE由2.6365涨到3.0536。6000的CE进一步涨到3.3613，MAE却没有更好。

旧日程实际warmup200，计划8000步才到1e-6；新日程也warmup200，但1500就到1e-6。实际runner参数覆盖模型配置字符串中的warmup500默认值。旧3000的LR约3.60e-5，因此不能把“旧checkpoint3000好”翻译成“固定3000余弦日程已验证”。

## 5. State依赖度

旧完整版3000在相同图像/标签上，原state MAE0.01217783、中性state0.01217860、打乱state0.01217796，预测变化很小。这说明该模型在这组留出数据上对这些state干预不敏感；干预可能OOD，也不等于去state重训一定无影响。

## 7. 证据范围

仅对PiperX558条最终成功人工示范做了此轮对照：502训练，56留出，按episode分离，统计仅用训练集。留出10%反复用于选模型，本质是验证集，不是无偏最终测试集。训练eval固定56条子集，不是全部502条训练数据。
尚无多seed重复；episode间可能存在采集session相关性。图中MAE是归一化倒计时误差，换算系数14882/30=496.0667秒/单位；不是成功率、机器人动作误差或真实任务进度误差。全成功数据不能验证失败判别、RL收益或真机提升。叠衣服/笔袋不能直接继承此结论。
CE与MAE衡量的对象不同：CE惩罚目标邻近桶概率不足，MAE只看201桶概率加权均值。分布变得过尖可能导致CE升高而均值误差小幅下降；现有覆盖率数据支持过度自信，但没有对每个桶给出独立标签充分性结论。
当前保存的轨迹指标使用稀疏帧差分/排序，不是固定50帧的Bellman residual；旧extended review仍未跑，不声称已有实际RL优势检验。
